# devlog — clinical-annotation-tools

The decision log is split into one file per dated entry under [`devlog/`](devlog/).
Start at **[`devlog/index.md`](devlog/index.md)** for the full list (newest first),
and see [`devlog/backlog.md`](devlog/backlog.md) for the running deferred / not-done list.

To add a decision: write a new `devlog/NN-slug.md` (next number, chronological —
so the newest entry has the highest `NN`), record the *why* not just the *what*,
and link it at the **top** of the entry list in `devlog/index.md`.
